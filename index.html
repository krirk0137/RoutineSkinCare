Skincare Routine

เป้าหมาย: สิวน้อยลง รอยจางลง ผิวเรียบขึ้น ผิวนุ่มแข็งแรง และสีผิวสม่ำเสมอ

ใช้ของให้น้อยชิ้น แต่ใช้ให้ถูกเวลาและสม่ำเสมอ

🌅 เช้า — ทุกวัน

  1. 1Cleanser

    ล้างหน้าเบา ๆ ไม่ถูแรง

  2. 2Serum

    เลือก 1 ตัว: hydration / ลดรอย / สิว

  3. 3Spot Treatment

    แต้มเฉพาะจุดที่มีสิว ไม่ต้องทั่วหน้า

  4. 4Moisturizer

    เลือก 1 ตัวตามสภาพผิว

  5. 5Sunscreen

    SPF 50+ ห้ามข้าม

🌙 กลางคืน — เลือกตามวัน

🟢 Basic Night

Cleanser → Serum → Moist

ใช้วันที่ไม่ได้ลง active แรง

🟣 Retinal / Retinol

Cleanser → Retinal → Moist

เริ่ม 2×/สัปดาห์ ช่วยสิวอุดตัน, texture, รอยสิว — ทาบาง ๆ ทั่วบริเวณเสี่ยงสิว ไม่ใช่แต้มจุด

🔴 Benzoyl Peroxide

Cleanser → BPO/Spot → Moist

ใช้เฉพาะตอนมีสิวอักเสบ ห้ามทาแผลเปิด/ผิวถลอก

🔵 Mask

Cleanser → Mask → Moist

1–2×/สัปดาห์ เติมความชุ่มชื้น ถ้ามาสก์มี active ให้นับเป็น active night

🚨 กฎทอง

  • อย่าใช้ active หลายตัวพร้อมกัน — Retinal + BPO + AHA + BHA + active serum พร้อมกันเสี่ยงระคายเคืองสูง
  • Spot treatment ≠ Serum — spot รักษาเฉพาะจุด ส่วน serum ดูแลทั่วหน้า
  • Retinal ไม่ใช่ spot treatment — ทาชั้นบางบริเวณที่เป็นสิวง่าย ไม่ใช่แต้มหัวสิว
  • Moisturizer เลือกแค่ 1 ตัวก็พอ — ถ้าแห้งมากค่อยใช้ Gel แล้วตามด้วย Cream
  • ห้ามข้าม sunscreen ตอนเช้า — ช่วยไม่ให้รอยดำเข้มขึ้นและทำให้รอยสิวจางเร็วขึ้น
